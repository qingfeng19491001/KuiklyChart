# 股票图变体统一完善设计

## 目标与范围

完善 `StockChartDemoPage` 的 8 种股票图变体：K 线、OHLC、蜡烛柱、面积股票图、折线股票图、Renko、Kagi 和点数图。

所有变体同步成熟股票图应具备的通用主题、选择、提示、缩放和平移体验；各图特有的指标只在语义适用时提供。页面仍是股票图组件陈列 Demo，不扩展为股票详情页，不加入行情头部、盘口或资讯。

## 现状

- `StockChart` 使用 `CartesianInteractiveView`，已具备点击、视口、平移、缩放、复位和可选十字准星基础设施。
- 另外 7 种由 `AdvancedChartView` 承载，均有点击提示，但只有面积图、折线图和 Kagi 支持视口操作，交互表现不一致。
- 当前主题只有手工色值配置，没有面向股票图的浅色/深色预设。

## 架构方案

1. 只在 Demo 外层增加按钮和提示：改动小，但公共组件自身仍不具备一致交互。
2. 为两套渲染视图提取统一的股票图交互协议和计算工具，并由各变体按统一协议实现：推荐。保留现有组件入口，改动可控。
3. 将全部高级股票图迁移到 `CartesianInteractiveView`：长期结构最统一，但本次会同时重写 7 种绘制流程，风险和回归面过大。

采用方案 2。统一公共配置与行为，暂不强制合并两套渲染基类。

## 通用交互协议

8 种股票图统一支持：

- 点击或长按定位最近数据项，并以统一样式高亮；再次点击空白区域清除选择。
- Tooltip 使用主题化浮层，显示标签和该图可表达的核心数据。
- 显示垂直定位线；具有连续价格 Y 值的图可同时显示水平准星。
- 单指横向平移、双指缩放、双击复位；初始窗口靠近最新数据。
- 视口限制在有效数据范围内，缩放和平移后保持选择、标签和命中测试一致。
- `LIGHT` / `DARK` 股票主题预设，并允许现有 `theme {}` 继续覆盖具体颜色。
- 保持现有点击和视口事件；为高级股票图补充选择变化事件，以便业务层同步信息面板。

时间序列、砖形、Kagi 和点数图都能横向浏览，但命中与 Tooltip 内容按各自数据结构计算，不伪造不具备的 OHLC 字段。

## 各变体专属能力

| 变体 | 通用交互 | 专属展示 |
| --- | --- | --- |
| K 线 | 全部 | MA5/10/20/30、可选成交量副图、OHLCV Tooltip |
| OHLC | 全部 | 开盘左刻、收盘右刻、OHLC Tooltip |
| 蜡烛柱 | 全部 | 加宽实体、OHLC Tooltip；不默认重复成交量副图 |
| 面积股票图 | 全部 | 收盘趋势和渐变面积 |
| 折线股票图 | 全部 | 连续收盘趋势 |
| Renko | 全部 | 砖块方向、价格 Tooltip |
| Kagi | 全部 | 转折、线宽变化、价格 Tooltip |
| 点数图 | 全部 | X/O 列方向、列高度 Tooltip |

均线和成交量不是所有股票图的通用能力，只加入第 1 个专业 K 线变体；其他 7 种同步的是交互、主题、视口和信息反馈。

## 公共 API

`OhlcPoint` 在末尾新增可选 `volume` 字段，默认 `null`，保留现有构造调用兼容性。

`StockChartAttr` 增加：

- `movingAverages`：均线周期、颜色和显隐。
- `volumePanel`：显隐、主副图区比例、成交量均线配置。
- `preset`：`LIGHT` / `DARK` 股票主题预设。

`AdvancedChartInteractionConfig` 对齐公共股票交互语义，补充十字准星、长按定位、视口边界和初始锚点配置；现有字段保持兼容。

## 专业 K 线 Demo

第 1 张卡片标题为“专业 K 线图”。顶部采用两级周期选择：常用 Tab 为“日 K / 周 K / 月 K”，右侧“更多 ▼”包含“1 分 / 5 分 / 15 分 / 30 分 / 60 分 / 120 分 / 季 K / 年 K”。周期控件属于 Demo 组合层，不进入 `StockChart` 绘图 API。

卡片从上到下展示周期栏、MA 图例、K 线主图区和可选成交量副图区，并提供浅色/深色预设切换。每个周期传入对应 OHLCV 样本数据。

“分时”和“五日”属于连续价格走势，继续由面积股票图和折线股票图变体承担，不混入 K 线周期菜单。

## 渲染与数据流

K 线主副图区使用同一个 Canvas 和共享 X 视口，价格与成交量各自计算 Y 范围。垂直准星贯穿主副图区，水平准星只位于主图区；无成交量数据时副图区不占高度。

高级股票图统一使用归一化视口窗口。渲染、命中测试、标签、选中引导线和事件都消费同一个可见范围，避免缩放后提示错位。
